# 投資者性格探索（線上版）

線上網址：https://xuecu.github.io/investor-personality-quiz-web/
（GitHub Pages，從 `main` 分支根目錄自動部署；推上 `main` 約 1～2 分鐘後就會上線）

## 架構：純靜態網頁 + Google Apps Script，沒有自己的伺服器

```
作答者瀏覽器 ──(POST 聯絡資料／作答結果)──▶ Google Apps Script 網頁應用程式 ──▶ Google 試算表
   ▲  index.html（測驗＋結果同一頁）                     （部署網址寫在 config.js 的 SUBMIT_URL）
   └─ GitHub Pages
```

- **沒有 `server.js`、`public/`、`package.json`**，這個 repo 從來沒有過；不需要 Node，也不需要 build。
- 後端是 Google Apps Script，程式放在 [`apps-script/`](apps-script/)，部署方式見那裡的 README。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 線上實際跑的檔案：`.js` 都已內嵌在裡面（單檔版），改題目、改流程要改這裡 |
| `quiz-core.js`、`shared.js`、`icons.js`、`config.js` | 跟 `index.html` 裡內嵌的內容一樣的獨立檔，方便閱讀與比對；**改了要同步到 `index.html` 的對應 `<script>` 區塊** |
| `config.js`（及 `index.html` 內嵌的那份） | 收件網址 `SUBMIT_URL`、正式網址 `SITE_URL`、表單文案 |
| `apps-script/` | Google 試算表那邊的收件程式與部署說明 |

## 測驗流程與題目（程式內版本號 `8.3`，2026-11-17 上線）

1. 封面 → **先填聯絡資料**（稱呼、年齡、Email 或電話擇一、勾同意）→ 才開始作答
2. 性格情境題 15 題 → 金融小挑戰 3 題 → 你的現況 9 題 → 學習規劃 2 題（想了解的投資領域、每月學習預算）
3. 看結果：開始前填過資料的人，學習地圖與教練的信直接解鎖

- 原本的 27 題順序與文字都沒有變；2026-11-17 只**新增**年齡、投資領域、學習預算三題。
- 選「還沒開始投資」的人會**自動跳過 3 題**（投資年資、最近一次買進、這幾年遇過的情況），這是原本就有的設計，不是題目被刪。
- 新增的三題**不計分、不寫進結果網址的作答代碼**，所以舊的結果連結都還打得開。

### 版本號說明
commit 標題在 2026-10-19 就寫過「v8.3」，但當時程式內的版本號其實是 `8.1`；2026-11-17 這一版把程式內版本號改成 `8.3`。
看版本請以試算表「測驗版本」欄（＝程式內 `quiz-core.js` 的 `VERSION`）為準：`8.1` 是舊流程，`8.3` 是先填資料的新流程。

## 改版注意
- 改題目或計分會影響舊的結果連結（網址 `#a=` 後面存的是作答）；新增「只收資料、不計分」的題目請照 `EXTRA_QS` 的做法，不要放進作答代碼。
- 畫面之間的連結只改網址 `#` 後面（`shared.js` 的 `LINK`），不要寫檔名。
- 推送前先跟其他協作者確認：推上 `main` 就直接上線。若同時要改 Apps Script，**先部署 Apps Script，再推網頁**，否則新欄位會被舊程式丟掉。
